# administration workstations

Aso is the primary workstation used to administer Gusuku and Fujigoko. It is also the main personal desktop and most powerful non-server PC, used for gaming and photography.

While physical Gusuku deployment is paused until the November 2026 move, Aso is the temporary test bed for [local AI experiments](../experiments/local-ai/README.md). All associated documentation, model tests, transcripts and tooling belong to Gusuku. The experiment does not make Aso part of the disposable lab host inventory.

| Workstation | Main role | Platform |
| --- | --- | --- |
| aso | Main desktop and primary server administration; temporary local-AI test bed | Arch Linux / KDE |
| ontake | Main gaming laptop; alternative administration | Bazzite / KDE |
| norikura | Everyday portable browsing and off-site Tailscale tinkering | Arch Linux / COSMIC |
| azuma | Everyday portable browsing and off-site Tailscale tinkering | macOS |

See the [shared workstation inventory in Fujigoko](https://github.com/s-pollard/fujigoko/blob/main/hosts/workstations.md) for hardware and confirmed tools, and [Home computer notes](https://github.com/s-pollard/home/tree/main/electronics/computers) for personal equipment details.

These are personal clients used to access the lab, not disposable lab hosts. They retain Japanese mountain/volcano names. Gusuku physical lab hosts use the castle names shown in the README.

Gusuku may be powered off, broken, or rebuilt without taking away the personal workstations or required Fujigoko services. Lab identity, DNS, or other experiments must not become required for production administration.

The laptops provide alternative access if Aso is unavailable. Available tools are not evidence that every login or recovery path has been tested. Tailscale provides tailnet connectivity; exact endpoints, keys, credentials, and addressing remain private.

Aso's photos are backed up to Motosu. None of the laptops are backed up.
