## Primary technical references checked

- [Docker Compose startup order](https://docs.docker.com/compose/how-tos/startup-order/): health-gated dependencies wait for the configured healthcheck; this does not establish whole-application correctness.
- [SQLite online backup](https://www.sqlite.org/backup.html): a supported database-aware copy is distinct from a concurrent raw-file copy.
- [PostgreSQL SQL dumps](https://www.postgresql.org/docs/18/backup-dump.html): account for cluster-level roles and application files separately from a single-database dump.
- [Docker daemon access](https://docs.docker.com/engine/security/protect-access/): API access is an authority boundary; read-only socket mount syntax is not API method authorization.
- [systemd.timer](https://www.freedesktop.org/software/systemd/man/latest/systemd.timer.html): persistent scheduling and service success are separate evidence.
