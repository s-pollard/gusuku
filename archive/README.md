## local AI

The local-AI model-selection project is closed as of 2026-10-25. **Qwen3.8-27B-UD-Q4-K-M is the committed model for the homelab-helper role.** The archived material remains available for provenance, comparison, and future reference, but it is no longer an active evaluation program.

- `local-ai/v4/` — final v4 evaluation kit, prompts, fixtures, launchers, evaluator material, and supporting tooling moved from the former active `experiments/local-ai/` tree.
- `local-ai/evaluation-roadmap.md` — retired 1–24 evaluation roadmap.
- `local-ai/evaluation-comparison-set-1-24.md` — retired comparison pack derived from the 1–24 roadmap.
- `local-ai/results/` — historical model runs and reviewed results.
- `local-ai/reviews/` — historical model and agent reviews.
- `local-ai/agents/` — Hermes and Odysseus setup notes.
- [Local AI custom exports](local-ai/custom-exports/README.md) — superseded custom/pasted transcript recoveries retained for provenance.

Archived 1–24, 00–34, and v4 material should be treated as historical evidence tied to the exact test version and model configuration that produced it. Do not treat old scores as current model qualification without deliberately reopening the evaluation.

The default direction is now to use **Qwen3.8-27B-UD-Q4-K-M** rather than continue routine candidate testing. Reopen model selection only for a concrete reason such as a demonstrated capability gap, a major hardware change, or a materially better model.
